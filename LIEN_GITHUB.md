# Lien GitHub — Projet 5

## API de Gestion d'un Inventaire de Produits

**Dépôt GitHub (public) :**

https://github.com/jacquessiyou4/spring-boot-projet-5-inventory-api

---

### Description
Gestion des produits, suivi des mouvements de stock et alertes automatiques sur stock bas.

### Auteur
SIYOU NOUKIMI JACQUES

### Stack technique
Spring Boot 3.3 · Java 17 · Spring Data JPA · PostgreSQL 15 · Docker Compose · Swagger (springdoc-openapi)

### Documentation de l'API
Une fois l'application démarrée, la documentation Swagger UI est accessible sur :

    http://localhost:8080/api/swagger-ui.html

### Démarrage rapide
```bash
git clone https://github.com/jacquessiyou4/spring-boot-projet-5-inventory-api.git
cd spring-boot-projet-5-inventory-api
docker compose up -d --build
```

Les instructions détaillées d'installation et de test figurent dans le fichier `README.md` du dépôt.
